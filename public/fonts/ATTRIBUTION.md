# Typography Attribution — Dace

Dace uses locally bundled open-source typefaces distributed under the SIL Open Font License 1.1:

1. **Newsreader Variable**
   - Designer: Production Type (commissioned by Google)
   - Classification: Editorial & Literary Serif with optical sizing
   - Usage: Conceptual titles, journal headings, and expressive quotations
   - License: SIL Open Font License, Version 1.1

2. **Manrope Variable**
   - Designer: Mikhail Sharanda
   - Classification: Geometric Interface Sans-Serif with humanist warmth
   - Usage: Primary workspace interface, navigation controls, search inputs, badges, and metadata
   - License: SIL Open Font License, Version 1.1

3. **Space Grotesk**
   - Designer: Florian Karsten
   - Classification: Geometric sans-serif for interface and display typography
   - Usage: Cinematic display headings, navigation, buttons, and record titles
   - License: SIL Open Font License, Version 1.1
   - Source: <https://github.com/floriankarsten/space-grotesk>

4. **IBM Plex Mono**
   - Designer: IBM
   - Classification: Monospaced technical typeface
   - Usage: Commands, shortcuts, timestamps, codes, and metadata
   - License: SIL Open Font License, Version 1.1
   - Source: <https://github.com/IBM/plex>

Additional licence files are bundled with the self-hosted font copies in
`src/assets/fonts/space-grotesk/OFL.txt` and `src/assets/fonts/ibm-plex-mono/OFL.txt`.
